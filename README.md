# Introspective Self-Knowledge as a Memory of Learning

Code and results for the article by Manuel F. Caro and Raúl E. Toscano (Universidad de Córdoba), submitted to the *Journal of Artificial Intelligence Research*.

Everything runs on a standard processor. The datasets are generated by the code or ship with scikit-learn.

## Contents

| File | What it does | Paper |
|---|---|---|
| `code/exact_leaves.py` | Exact type-2 sensitivity in the two-leaves model | Table 1 |
| `code/exact_bounds.py` | Checks the closed form and the bounds of Theorem 3 | Table 2 |
| `code/ia_experiments.py` | Networks, trees, forests and nearest-neighbour classifiers on three task families, two output channels | Figures 2–3, Table 3 |
| `code/probe_control.py` | Per-agent probes on full activations and monitor-seed variability | Section 6.3 |
| `code/lm_experiment.py` | Small transformers on memorized facts and modular addition | Figure 4 |
| `code/lm_probe.py` | Same, with up to 1024 samples and per-agent probes on the residual stream | Section 6.4 |
| `code/lm_inf.py` | Observer with exact answer distributions (limit of unlimited sampling) | Section 6.4 |
| `code/make_*.py` | Figures | Figures 1–4 |
| `notebooks/pretrained_lms_colab.ipynb` | GPT-2 and Pythia on capitals and two-digit addition (Colab) | Discussion |
| `results/` | `summary.json` for every run | all |

## Running

```bash
pip install numpy scipy scikit-learn matplotlib torch
cd code
python exact_leaves.py && python exact_bounds.py
python ia_experiments.py --out ../results/results_score --channel score
python ia_experiments.py --out ../results/results_label --channel label
python probe_control.py --out ../results/results_probe
python lm_experiment.py --out ../results/results_lm
python lm_probe.py --out ../results/results_lm2
python lm_inf.py --out ../results/results_lm_inf
```

Each script prints a one-line summary per condition and writes `summary.json`. With two processor cores the full set takes a few hours; `--quick` gives a fast check for `ia_experiments.py` and `lm_experiment.py`.
